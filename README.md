# Deena Dayal B K - Portfolio Website

Modern, optimized portfolio built with Next.js 14, TypeScript, and Tailwind CSS.

## 🚀 Features
- **Responsive Design** - Mobile-first approach
- **Dark Theme** - Modern dark mode with cyan accents  
- **Fast Performance** - Optimized for Lighthouse 90+
- **SEO Optimized** - Meta tags and structured data
- **Dynamic Content** - Projects and data from TypeScript files
- **Accessible** - WCAG 2.1 compliant

## 📦 Tech Stack
- Next.js 14+
- TypeScript
- Tailwind CSS
- Lucide React Icons
- Vercel Deployment

## 🛠️ Installation

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

## 📁 Structure
```
├── app/              # Next.js app router
├── components/       # React components
├── lib/              # Data & utilities
├── public/           # Static files
└── package.json
```

## 🎨 Sections
1. **Hero** - Introduction with CTAs
2. **Projects** - Featured work with GitHub links
3. **Experience** - Professional timeline
4. **Leadership** - ISTE President experience
5. **Skills** - Technical & professional skills
6. **Certifications** - Credentials & achievements
7. **About** - Personal bio
8. **Contact** - Contact form & social links

## 🚀 Deploy to Vercel

```bash
git push origin main
```

Then connect your GitHub repo to Vercel.
